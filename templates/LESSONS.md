## Loop rules (graphify reflect model)

- Every lesson carries **provenance**: `[SAID]` — the user said it directly; `[INFERRED]` — Claude inferred it; `[DATA]` — from tests/files.
- Every lesson carries an **outcome signal**: `useful` / `dead_end` / `corrected`, and a **date**.
- **Corroboration gate:** a lesson becomes **Trusted** only after ≥2 independent confirmations. A single observation = Tentative.
- **Time-decay (half-life ~30 days):** a fresh `corrected`/`dead_end` overrides an old `useful`. On conflict, recency wins → move to Contested.
- **Sidecar principle:** only lessons about *how to work with the user* live here. Facts about the user live in [[about-me]] and source pages, not here.
- Keep this file short (it loads every session). Stale/refuted lessons go to the Archive at the bottom.
